# Android dashboard

The app launches DashboardActivity with Home, Xbox, Commands, Tasks, Settings and Logs. Owner XUID is validated and saved in private preferences. Xbox login, bot connection and commands remain unavailable pending a live engine. Diagnostic foreground service and stop controls are available.

No Bedrock protocol runtime, Microsoft login, or game control is bundled. Verify actual APK size from the artifact ZIP; do not confuse the artifact link with the APK itself.
